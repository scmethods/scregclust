# Get the average number of active regulators per module

Get the average number of active regulators per module

## Usage

``` r
get_avg_num_regulators(fit)
```

## Arguments

- fit:

  An object of class `scRegClust`

## Value

A [`data.frame`](https://rdrr.io/r/base/data.frame.html) containing the
average number of active regulators per module for each penalization
parameter.
